# TikTok H5 项目

## 项目简介

这是一个使用 Vue 3 开发的 H5 版本短视频应用，类似抖音（TikTok），支持视频播放、滑动切换、点赞、评论等功能。

## 技术栈

- **框架**：Vue 3.4+
- **构建工具**：Vite 5.0+
- **状态管理**：Pinia 2.1+
- **路由**：Vue Router 4.2+
- **UI组件**：Vant 4.0+
- **HTTP客户端**：Axios
- **工具库**：@vueuse/core, dayjs

## 核心功能

### 1. 视频播放
- 垂直滑动的视频列表
- 自动播放当前可见视频
- 滑动切换时自动暂停/播放
- 支持单击暂停/继续
- 双击点赞动画

### 2. 交互功能
- 双击屏幕点赞，显示爱心动画
- 右侧操作栏：点赞、评论、分享
- 底部显示作者信息和文案
- 支持关注/取消关注

### 3. 评论系统
- 底部弹窗显示评论列表
- 支持发表评论
- 显示评论点赞数
- 支持评论点赞

### 4. 个人主页
- 显示用户信息（头像、昵称、签名）
- Tab切换：作品、动态、喜欢
- 展示用户视频列表
- 支持关注/取关

### 5. 视频上传
- 支持选择视频文件
- 上传进度显示
- 视频封面截取
- 填写视频信息（标题、描述）

## 项目结构

```
src/
├── assets/      # 静态资源
├── components/  # 公共组件
│   └── VideoPlayer.vue  # 视频播放器组件
├── views/       # 页面组件
│   ├── Home.vue        # 主页（视频列表）
│   ├── Profile.vue     # 个人主页
│   └── Upload.vue      # 视频上传页面
├── store/       # Pinia状态管理
│   └── index.js        # 视频和用户状态
├── api/         # API接口
├── utils/       # 工具函数
│   └── format.js       # 数字格式化工具
├── router/      # 路由配置
│   └── index.js        # 应用路由
├── App.vue      # 根组件
└── main.js      # 应用入口
```

## 运行项目

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

### 预览生产版本
```bash
npm run preview
```

## 使用说明

1. **视频浏览**：上下滑动或使用鼠标滚轮切换视频
2. **视频控制**：点击视频可暂停/继续播放
3. **点赞**：双击屏幕或点击右侧爱心按钮
4. **评论**：点击右侧评论按钮查看和发表评论
5. **分享**：点击右侧分享按钮分享视频
6. **个人主页**：点击作者头像进入个人主页
7. **上传视频**：点击底部上传按钮上传新视频

## 键盘快捷键

- **上箭头/左箭头**：切换到上一个视频
- **下箭头/右箭头**：切换到下一个视频

## 注意事项

- 视频播放功能需要在HTTPS环境下才能正常工作
- 上传功能需要配置合适的CORS策略
- 当前项目使用模拟数据，实际项目中需要对接真实的后端API

## 性能优化

- **视频预加载**：提升播放体验
- **路由懒加载**：减少初始加载体积
- **代码分割**：优化打包大小
